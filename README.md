# Portfolio – Nguyễn Thiện Tâm

Đây là bộ mã nguồn Portfolio cá nhân, có thể chỉnh sửa và xuất bản bằng **GitHub Pages**.

## Cấu trúc thư mục

- `index.html`: Trang chủ Portfolio.
- `assets/css/style.css`: Giao diện và định dạng.
- `assets/js/script.js`: Tương tác menu và năm ở chân trang.
- `assets/images/`: Lưu ảnh cá nhân, ảnh minh họa.
- `files/`: Lưu tài liệu Word, PDF, PowerPoint.
- `projects/`: Sáu trang bài tập riêng.

## Cách đưa lên GitHub Pages

1. Giải nén file ZIP trên máy tính.
2. Đăng nhập GitHub và tạo repository mới, ví dụ `nguyen-thien-tam-portfolio`.
3. Chọn **Public** rồi tạo repository.
4. Mở repository → **Add file** → **Upload files**.
5. Tải toàn bộ nội dung bên trong thư mục này lên (đảm bảo `index.html` nằm ngay ở thư mục gốc repository).
6. Chọn **Commit changes**.
7. Vào **Settings → Pages**.
8. Trong **Build and deployment**, chọn **Deploy from a branch**.
9. Chọn branch `main`, thư mục `/(root)` rồi nhấn **Save**.
10. Chờ GitHub xuất bản website; địa chỉ sẽ hiển thị ngay tại mục Pages.

## Cách chỉnh sửa

- Sửa nội dung chữ: mở `index.html` hoặc trang tương ứng trong `projects/`.
- Sửa màu sắc, font, khoảng cách: mở `assets/css/style.css`.
- Thêm ảnh: tải ảnh vào `assets/images/`, sau đó chèn đường dẫn ảnh vào HTML.
- Thêm tài liệu: tải tệp vào `files/`, sau đó tạo liên kết đến tệp, ví dụ `files/ten-tai-lieu.pdf`.

## Việc cần cập nhật trước khi nộp

- Bổ sung thông tin trường, khoa, lớp, mã sinh viên và học phần nếu đề bài yêu cầu.
- Thay nội dung mẫu bằng thông tin và sản phẩm thật của bạn.
- Bổ sung đủ nội dung cho 6 bài tập.
- Kiểm tra quyền xem công khai đối với các tệp được lưu trên dịch vụ đám mây.
- Ghi rõ công cụ AI và mục đích sử dụng nếu có.
- Tự kiểm tra các liên kết trước khi gửi giảng viên.

Lưu ý: Các nội dung kỹ năng, sở thích và mô tả trong bản mẫu cần được bạn chỉnh lại cho đúng với bản thân.
