# Portfolio Nguyễn Thiện Tâm

## Cấu trúc
- `index.html`: Trang chủ
- `gioi-thieu.html`: Giới thiệu
- `hoc-van.html`: Học vấn
- `nang-luc.html`: Năng lực và định hướng
- `du-an.html`: Danh sách 6 bài tập
- `lien-he.html`: Liên hệ
- `style.css`: Giao diện dùng chung
- `assets/avatar.jpeg`: Ảnh đại diện

## Đưa lên GitHub Pages
1. Giải nén thư mục này.
2. Mở repository GitHub của bạn.
3. Tải toàn bộ các tệp và thư mục bên trong `portfolio-nguyen-thien-tam` lên thư mục gốc repository (không tải nguyên thư mục lồng bên ngoài).
4. Commit changes.
5. Vào Settings > Pages, chọn Deploy from a branch, branch `main`, folder `/ (root)`, rồi Save.
6. Mở địa chỉ GitHub Pages của repository.
